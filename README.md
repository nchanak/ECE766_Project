# ECE766_Project

To visit site: https://nchanak.github.io/ECE766_Project/

Since we would require separate hosting for running inference on the models used in WaldoGen,
you must clone the repo and host the site yourself to generate and play Where's Waldo.

Do: pip install -r requirements.txt

Run with: uvicorn server:app --host 127.0.0.1 --port 8000
